# 香港夏季高温与降雨分析

AMA2233 Data Analytics and Visualization 课程小组项目。

研究题目：**香港夏季的高温与降雨如何变化——长期趋势与季节分布分析**。

## 当前计划

请先阅读 [项目总体计划](项目总体计划.md)。当前范围为香港天文台站1991–2025年、每年6–8月，准备分析长期趋势、月份分布和温度与降雨的关联。

计划制作五张核心图：

1. 夏季平均气温年度趋势。
2. 夏季总降雨量年度趋势。
3. 早期与近期各月平均气温对比。
4. 早期与近期各月平均降雨量对比。
5. 夏季温度与降雨量关联散点图。

数据尚未分析，仓库中的计划不代表实际研究结果。
